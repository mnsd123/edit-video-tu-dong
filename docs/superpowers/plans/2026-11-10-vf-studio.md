# vf studio — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web app chạy trên máy (`vf studio lo-NN`) để sửa `edl.json` của một lô — chữ, đồ hoạ, hiệu ứng, timeline kéo thả — xem trước trực tiếp, xuất phiên bản mới từ biến thể đã có, và render lại bằng pipeline `vf render` sẵn có.

**Architecture:** Mọi luật và phép sửa EDL nằm trong Python (`vf/studio/`, có test) và được phơi qua API FastAPI chỉ nghe `127.0.0.1`. Frontend React (`studio/web/`) giữ bản nháp biến thể, gọi API cho mọi phép biến đổi/lint/lưu, và xem trước bằng `@remotion/player` với composition `Preview` mới (đoạn nguồn + `Overlay` có sẵn). Render chạy `vf render --only` trong tiến trình con.

**Tech Stack:** Python 3.11, pydantic 2, typer, FastAPI ≥ 0.115, uvicorn ≥ 0.30, httpx (test); Vite 6, React 19, TypeScript, `@remotion/player` cùng phiên bản `remotion` trong `remotion/package.json`, vitest.

**Spec:** `docs/superpowers/specs/2026-11-10-vf-studio-design.md`

## Global Constraints

- Server chỉ bind `127.0.0.1`, cổng mặc định `8765`; `--port` đổi được.
- Chỉ ghi vào `jobs/<lô>/edl.json`, `jobs/<lô>/history/`, và `<drive_root>/out/<lô>/review.csv`. Không bao giờ ghi vào `sources_dir` (`source gốc`) hay `video tham khảo`.
- Ghi `edl.json` bằng `json.dumps(obj, ensure_ascii=False, indent=1) + "\n"`, UTF-8.
- Biến thể không bị sửa phải giữ nguyên `variant_fingerprint` (không render lại vì studio).
- Mọi tên nguồn qua `vf.paths.nfc`; mọi đường dẫn file mở bằng `vf.paths.child`.
- Mọi thông báo lỗi/hiển thị cho người dùng bằng tiếng Việt.
- `history/` giữ tối đa 50 bản mới nhất.
- Một lô chỉ một lượt render một lúc.
- Chạy được Mac (Apple Silicon) và Windows; không dùng lệnh shell riêng nền tảng trong code studio.
- Frontend không tự cài luật cắt/lint/tạo phiên bản — gọi API.

### Task 3: Phép sửa timeline (thuần, có bắt dính)

**Files:**
- Create: `vf/studio/timeline.py`
- Test: `tests/test_studio_timeline.py`

**Interfaces:**
- Consumes: `Variant`, `Segment`, `Word` (`vf.transcribe`)
- Produces:
  - `@dataclass OpResult: variant: Variant; notes: list[str]` (notes = cảnh báo tiếng Việt, ví dụ chữ bị gỡ)
  - `piece_offsets(v: Variant) -> list[float]` — giờ output bắt đầu mỗi piece (hook = 0) + tổng ở cuối
  - `move_piece(v, src: int, dst: int) -> OpResult` — chỉ số theo `v.pieces()`; `src`/`dst` = 0 nghĩa là hook
  - `trim_piece(v, i: int, start: float, end: float) -> OpResult`
  - `delete_piece(v, i: int) -> OpResult` — xoá hook → piece kế tiếp thành hook (phải ≤ 3 s, không thì `ValueError`)
  - `insert_piece(v, at: int, seg: Segment) -> OpResult`
  - `set_hook(v, i: int) -> OpResult` — đổi chỗ piece i với hook
  - `snap_time(t: float, words: list[Word], cuts: list[float], edge: Literal["start","end"], window: float = 0.25) -> float`

**Thuật toán neo (không suy ra được từ chữ ký, phải theo đúng):** mỗi overlay/graphic/effect được neo vào piece chứa thời điểm bắt đầu của nó (`start`, với effect là `at`; đúng biên → piece phía sau). Lưu `delta = t - offset_cũ[piece]`, tính trong **giờ nguồn** = `piece.start + delta`. Sau phép sửa: piece còn tồn tại → giờ output mới = `offset_mới[piece] + (giờ_nguồn - piece_mới.start)`; giữ nguyên độ dài phần tử. Nếu giờ nguồn rơi ngoài `[piece_mới.start, piece_mới.end)` hoặc piece bị xoá → gỡ phần tử và thêm note `"đã gỡ chữ '<text 20 ký tự>' (đoạn bị cắt/xoá)"` (graphic: `"đã gỡ đồ hoạ <kind>"`). Phần tử còn lại mà `end` vượt cuối piece-cuối-cùng của video → kẹp `end` = tổng thời lượng. Mọi kết quả qua `Variant.model_validate` (hook > 3 s → `ValueError` của pydantic, giữ thông điệp).

`snap_time`: ứng viên = `w.start - 0.02` (edge start) hoặc `w.end` (edge end) của mọi chữ + mọi `cuts`; chọn ứng viên gần nhất trong `window`, không có → giữ `t`. Làm tròn 2 chữ số.

**Công thức:**
- `duplicate`: bản sao.
- `preset` `{"preset": str}`: đổi preset; preset không có trong hồ sơ → `ValueError`; overlay có `style` thuộc hệ chữ cũ (`lower`/`vox`/`plain`) đổi sang `overlay_style` của preset mới (`cta`, `tag`, `hook`, `commit` giữ nguyên).
- `hook_from` `{"variant": id}`: thay `hook` bằng hook của biến thể kia + mang theo overlay/graphic/effect nằm trong khoảng hook của biến thể kia; bỏ phần tử cũ trong khoảng hook; dời phần còn lại theo chênh lệch độ dài hook; `hook_type` lấy theo biến thể kia.
- `cutdown` `{"seconds": float}`: giữ hook, mọi piece `protect` hoặc chapter `result`/`proof`, và piece `cta` cuối; bỏ dần piece còn lại từ piece **dài nhất** tới khi tổng ≤ seconds × 1,1 (dùng `delete_piece` để chữ đi theo); không đạt → note `"không cắt được xuống <s> s: còn <x> s"`. Đặt `cutdown_of=base_id`, id = `<base>-ngan` (trùng → `next_id`).
- `cta` `{"label": str, "sub": str | None}`: sửa `end_card` (graphic) cuối; không có → thêm `end_card` 2,8 s cuối.
- `clean`: bỏ mọi `overlays` và graphic không phải `end_card`; giữ effects.
